# 抗菌药物识别词库配置 · 产品设计方案

> 版本：设计稿 v1 · 2026-09-13
> 定位：为「抗菌药物识别」提供可运维的词表底座。ICU 医嘱名称长、含溶媒与商品名、非抗菌药种类繁多，**必须用「广谱白名单 + 非抗菌黑名单」双表匹配**，才能稳定回答「这条医嘱是不是抗菌药」。本模块提供词表的可视化维护、HIS 药品字典训练与幂等升级脚本。

## 一、背景与定位

### 1.1 为什么需要独立词库

| 需求场景 | 依赖词库的位置 |
|---|---|
| 脓毒症集束化「1H 内是否使用广谱抗菌药」 | 广谱白名单 |
| 脓毒症集束化「抗菌药前留取血培养」 | 抗菌药最早开始时间 |
| 脓毒症集束化「抗菌药物系统参考值」（14 天窗口，**仅展示不入库**） | 白名单 + 黑名单 |
| 交班览表「在用抗菌药」展示 | 白名单 + 黑名单 |
| 第一维度抗感染决策「抗菌药开始时间」 | 白名单 |
| DDD 使用强度统计 | 药品名与 DDD 知识库匹配（间接） |

**核心矛盾**：非抗菌药（电解质、营养、中药、镇静镇痛、血管活性药…）有数千种，用黑名单穷举永远列不全；因此采用**白名单为主（必须命中）+ 黑名单兜底（命中即排除）**的双重策略。

### 1.2 设计原则

1. **白名单优先**：只认白名单，不认「不像抗菌药」的推断；
2. **黑名单兜底**：白名单误伤（如含「青霉素」字样的复方、含「头孢」字样的皮试液）时用黑名单扣除；
3. **配置即生效**：页面保存后**无需重启**，每次评估前从表刷新（表为空时回退代码内置默认词表，保证新环境可用）；
4. **升级幂等**：增量脚本一律 `WHERE NOT EXISTS`，不覆盖后台人工增删的词条。

## 二、匹配规则

```
isAntibiotic(医嘱名) =
      存在白名单词 w ∈ broad_spectrum 使 医嘱名.contains(w)
  且  不存在黑名单词 n ∈ non_antibiotic 使 医嘱名.contains(n)
```

- 采用**包含匹配**（`contains`），命中商品名、复方名、溶媒复合名（如「注射用哌拉西林钠他唑巴坦钠（特治星）」）；
- 白名单/黑名单均按 `status = 1` 过滤，支持随时停用某个词条而不删除（保留历史可追溯）；
- 词条冲突时**黑名单优先**（扣减）。

## 三、词表数据结构（`config_abx_word`）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | BIGINT AUTO | 主键 |
| `word_type` | VARCHAR | `broad_spectrum` 广谱抗菌药白名单 / `non_antibiotic` 非抗菌药黑名单 |
| `keyword` | VARCHAR | 匹配关键词（包含匹配） |
| `category` | VARCHAR | 分组，如「青霉素类 / 头孢类 / 碳青霉烯类 / 电解质 / 抗凝·血液净化 / 降压·心血管 / 抗肿瘤」 |
| `remark` | VARCHAR | 备注（如「HIS药品字典训练补充」「内置默认」） |
| `status` | INT | 1 启用 / 0 停用 |
| `create_time` / `update_time` | TIMESTAMP | 审计字段 |

## 四、词表规模与训练来源

### 4.1 训练来源：HIS 药品字典

| 项 | 内容 |
|---|---|
| 数据源 | HIS `config_drug` 表（`is_antibiotics = 1` 的全身用抗菌药） |
| 样本量 | 127 条记录 / 83 个通用名 |
| 白名单补充 | 36 个核心通用名（青霉素类、头孢类、碳青霉烯类、喹诺酮类、糖肽类等） |
| 黑名单补充 | 19 个（抗肿瘤、强心、保肝、益生菌、多种微量元素等） |
| 已知局限 | HIS `is_antibiotics` 仅标记**全身用**抗菌药，**外用/眼科/妇科抗菌药标记为 0**（ICU 场景影响小，暂不补） |

### 4.2 词表当前规模

| 词表 | 条数 | 覆盖 |
|---|---|---|
| `broad_spectrum`（白名单） | 约 **61** 个关键词 | 青霉素类、头孢类（1~4 代）、碳青霉烯类、糖肽类、喹诺酮类、抗真菌类、硝基咪唑类、磺胺类、氨基糖苷类、大环内酯类、多黏菌素、替加环素等 |
| `non_antibiotic`（黑名单） | 约 **425** 个关键词 | 电解质、维生素、营养、抑酸、镇静镇痛、肌松、抗凝·血液净化（含 CRRT/枸橼酸/置换液）、血管活性、抗心律、利尿、化痰、造影剂、激素、血制品、降糖降脂、抗组胺、精神药物、外用消毒、中药等 |

## 五、升级与运维脚本

| 脚本 | 用途 | 特点 |
|---|---|---|
| `sql/02_seed.sql` | 初始化内置词表 | 首次部署执行 |
| `sql/03_word_inc_v2319.sql` | v23.1.9 非抗菌药补词（抗凝/血液净化、降压/心血管等） | 幂等，**执行后无需重启后端**（每次打开页面自动从表刷新） |
| `sql/03_word_inc_v23111.sql` | v23.1.11 增量补词 | 幂等 |
| `sql/04_abx_word_training.sql` | 基于 HIS 药品字典的批量训练 | 幂等 `WHERE NOT EXISTS`，不覆盖人工维护结果 |

> 所有增量脚本统一写法：`INSERT ... SELECT ... FROM DUAL WHERE NOT EXISTS (SELECT 1 FROM config_abx_word WHERE word_type = ? AND keyword = ?)`，可重复执行。

## 六、后端接口（`/api/antibiotic/word-config`）

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | `/list` | — | 全部**启用**词条（按 word_type + category 分组返回） |
| GET | `/categories` | — | 全部分组枚举 |
| POST | `/add` | Body: `AbxWordConfig` | 新增词条（`wordType, keyword, category, remark`） |
| POST | `/update` | Body: `AbxWordConfig` | 修改词条 |
| POST | `/toggle` | `id, status` | 启用/停用（不删除，保留历史） |

服务实现要点：

- `listAllActive()`：仅返回 `status = 1`；
- **缓存策略：每次评估前重新加载**（不做本地长期缓存），保证页面修改即时生效；
- **空表回退**：`config_abx_word` 无数据时使用代码内置默认词表（白名单 60+、黑名单 500+），保证新环境不空转。

## 七、前端页面（`/page/abx-word-config`）

```
┌─ 顶部：词类型切换（广谱抗菌药白名单 / 非抗菌药黑名单） ─────────────────┐
├─ 搜索框：按关键词/分组过滤 ───────────────────────────────────────┤
├─ 分组折叠面板：按 category 分组展示词条（电解质 / 头孢类 / ...） ────────┤
│   每条：关键词 | 分组 | 备注 | 启用开关 | 编辑 | 删除                    │
├─ 新增词条弹窗：词类型 + 关键词 + 分组 + 备注 ─────────────────────────┤
└─ 顶部提示：词表为空时将使用系统内置默认词表 ───────────────────────────┘
```

- 支持批量查看「某分组下有多少词条」；
- 停用（而非删除）用于临时屏蔽误伤词条。

## 八、边界与风险

| # | 问题 | 影响 | 建议 |
|---|---|---|---|
| 1 | 包含匹配易误伤 | 如「复方磺胺甲噁唑」含「磺胺」（白名单命中，正确）；但「××霉素软膏」也会命中白名单 | 用黑名单补「软膏/乳膏/滴眼/外用」等形态词 |
| 2 | 外用药未纳入白名单 | ICU 影响小，但 DDD/交班统计会漏 | 视需求补入并加形态约束 |
| 3 | 新药/商品名未及时入词库 | 白名单漏判 → 集束化「广谱抗菌药」判不达标、交班不显示 | 定期用真实医嘱跑「未匹配清单」（建议新增报表） |
| 4 | 词条无优先级/互斥机制 | 冲突时仅靠黑名单优先 | 可引入正则或精确名优先 |
| 5 | 词库变更无审计 | 无法追溯「谁在何时停用了某词」 | 增加操作日志表 |
| 6 | 内置默认词表与 DB 词表可能不一致 | 新环境与老环境识别结果不同 | 上线时统一初始化一次并纳入变更管理 |

## 九、后续优化建议

1. 新增「**未匹配医嘱清单**」页面：把近期医嘱中「既不命中白名单、也不命中黑名单」的药品名列出来，一键加入白/黑名单，形成**闭环训练**；
2. 词条支持**正则表达式**与**排除词**，提高精确度；
3. 增加**词库版本号**与变更审计，供第一维度决策快照引用；
4. 与 HIS 药品字典**定时同步**（夜间任务），自动发现 `is_antibiotics` 变更。
