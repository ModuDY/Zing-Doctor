# 院感监测（VAP / CLABSI / CAUTI）与脓毒症筛查口径方案

> 目的：把"疑似院感患者自动筛查 + 医生确诊/排除 + 发生率自动回写质控"这三件事的**判定口径、数据来源、计算公式**定清楚，供院感科、信息科确认后再进入开发。
> 依据：CDC NHSN Patient Safety Component 现行监测定义（CLABSI / CAUTI / VAE）、Sepsis-3（2016）、国家《医院感染诊断标准》。
> 版本：v1.0（待院感科会签）

---

## 0. 一条不可逾越的边界

**系统只做"疑似筛查 + 证据罗列"，不做"院感确诊结论"。**

- 系统按规则把"带某类导管 + 相应部位培养/体温/WBC 异常"的患者标为**疑似名单**，并把证据按时间线摆出来；
- "确诊 / 排除 / 记录诊断依据"必须由医生（或院感科）在页面上手动点选，回写确诊标记；
- 发生率（分母）**只统计医生已确诊的事件**，疑似但未确认的不计入分子。

理由：NHSN 监测定义里大量判断（症状是否由其他部位解释、是否入院时已存在、是否同一菌）属于临床判断，自动规则容易把"培养阳性但非导管相关"误判成院感，直接污染质控指标。这与本系统既往"UNKNOWN 不当作无数据"的原则一致。

---

## 1. 通用计数规则（三类导管日/机械通气日共用）

依据 NHSN：置管当天 = 第 1 天；一天内任何时段导管在位都计 **1 个导管日**；拔除后同日再重新置入，导管日连续计、不中断。

系统用 `patient_tube` 表计算：
- 留置起：`tube_set_start_time`
- 留置止：优先 `tube_take_away_time`，其次 `tube_set_end_time`，二者皆空视为"仍在管"
- 每个自然日，只要 `start <= 当日 < end`（或 end 为空），计 1 日
- 排除：`del_flag = 1` 的记录

> 注：NHSN 规定导管必须**在位 ≥2 个连续自然日**才可能构成 CLABSI/CAUTI/VAP（事件当天或前一天仍在位）。置管当天发生的感染不计入导管相关。

## 2. 三类院感定义与数据映射

### 2.1 CLABSI（中心血管导管相关血流感染）

**NHSN 判定（全部满足）：**
1. 事件当天或前一天，中心血管导管在位 **>2 个连续自然日**（含拔管后 48h 内发病）；
2. 实验室确认血流感染（LCBI）：
   - 单次血培养分离到**公认致病菌**（非皮肤常驻菌）；**或**
   - ≥2 次血培养分离到**皮肤共生菌**，且合并发热（>38℃）/低血压/低体温之一；
3. 该菌不能归因于其他部位感染；入院时不存在、非潜伏期。

**我们库对应：**
| 要素 | 数据来源 | 可得性 |
|---|---|---|
| 中心血管导管在位/天数 | `patient_tube`（CVC、PICC 等，见 §4 分类字典） | ✅ 已核实有数据（CVC 1142 条、PICC 102 条） |
| 血培养结果 | `patient_info_lis_item` 培养类文本 | ⚠️ 目前为文本，未结构化"致病菌/共生菌/S-I-R" |
| 体温 | `config_observe_item` item_code=`oi_tiwen` | ✅ |
| 低血压/血管活性药 | 工作台已聚合血管活性药状态 | ✅ |
| 其他部位感染归因 | 诊断表 `patient_info_diagnosis` | ⚠️ 需医生判断 |

**自动筛查触发（疑似）**：带 CVC/PICC 且在位 ≥2 日 **且**（窗口内血培养阳性 **或** 体温>38℃ + 新用抗菌药）。

### 2.2 CAUTI（导尿管相关尿路感染）

**NHSN 判定（全部满足）：**
1. 留置导尿管（IUC）在位 **>2 个连续自然日**，事件当天或前一天仍在位；
2. 有 UTI 症状（发热/寒战/肋脊角痛等）——**无症状菌尿不计入**；
3. 尿培养阳性：≥2 种菌、其中一种为大量生长；**NHSN 2015 起念珠菌/真菌不计为 CAUTI 病原体**。

**我们库对应：**
| 要素 | 数据来源 | 可得性 |
|---|---|---|
| 导尿管在位/天数 | `patient_tube` tube_code=`tube_导尿管` | ✅ 数据量最大（3003 条） |
| 尿培养结果 | 培养类检验文本 | ⚠️ 文本，真菌/细菌未拆分 |
| 发热 | `oi_tiwen` | ✅ |
| 症状（肋脊痛等） | 无结构化字段 | ❌ 靠医生录入判断 |

**自动筛查触发（疑似）**：带导尿管且在位 ≥2 日 **且**（尿培养阳性 **或** 发热 + 新用抗菌药）。

### 2.3 VAP / VAE（呼吸机相关事件）

**NHSN 三层（注意：不是旧 VAP 直接定义）：**
- **VAC**：机械通气 ≥2 日后，先有 ≥2 天稳定氧合，再出现每日最低 PEEP 或 FiO₂ 升高（氧合恶化）；
- **IVAC**：VAC + 发热(>38) 或 WBC 异常 + 新用抗菌药且 ≥4 天；
- **Possible VAP（PVAP）**：IVAC + 脓性痰 **或** 下呼吸道标本培养阳性。

发生率分母为**机械通气日**（有创机械通气，不含无创通气，需与呼吸治疗师确认本院口径）。

**我们库对应：**
| 要素 | 数据来源 | 可得性 |
|---|---|---|
| 气管插管/机械通气天数 | `patient_tube`（气管插管类） | ✅ 约 997 条 |
| 每日最低 PEEP / FiO₂ | 呼吸机参数表（待核项目编码） | ❓ **关键缺口**：VAC 必须有每日最小 PEEP/FiO₂，需先确认 ICU 监护表是否结构化采集 |
| 体温、WBC | `oi_tiwen` / 检验 | ✅ |
| 痰培养 | 培养类文本 | ⚠️ 文本 |
| 脓性痰 | 无结构化 | ❌ 靠医生判断 |

> **重要提示**：VAC 层依赖每日 PEEP/FiO₂ 最小值。若 ICU 系统没有这两个参数的结构化每日数据，**VAE 自动化做不出来**，一期只能做"机械通气日 + 痰培养/发热"的粗筛，不能宣称实现 NHSN VAE 分层。这一项必须先到 ICU 库核实项目编码，再决定是否做 VAC。

## 3. 脓毒症智能筛查口径（Sepsis-3）

- **脓毒症**：感染 + SOFA 急性变化 ≥2 分（本院已有 SOFA 评分，可直接复用）；
- **脓毒性休克**：充分液体复苏后仍需血管活性药维持 MAP≥65 mmHg 且血乳酸 >2 mmol/L；
- **qSOFA 预警**（床旁快筛）：呼吸≥22 次/分、意识改变、收缩压≤100 mmHg，≥2 项即筛。

**我们库数据基础最成熟**：SOFA、乳酸、PCT、WBC、体温、血培养、集束化全部已有。自动输出"疑似脓毒症名单"，确诊/排除仍由医生操作。

**预警通道**：一期只做**系统内待办 + 页面弹窗**。短信、院内通讯（钉钉/企业微信）属二期，需信息科另行对接，不在本期范围。

## 4. 管路分类字典（基于真实 tube_code 分布，待院感科确认）

库内 `tube_code` 多达上百个、中英文/拼音混写。统计到的主要项：

| 建议归为 | tube_code 实测值（示例） | 用途 |
|---|---|---|
| 中心血管导管（算 CLABSI 导管日） | `tube_CVC管`(1142)、`tube_PICC`(102)、其他深静脉/PICC 变体 | 需院感科确认：PICC 是否计入、"其他深静脉"含哪些 code |
| 导尿管（算 CAUTI 导管日） | `tube_导尿管`(3003) | 已确认在用 |
| 机械通气（算 VAP 通气日） | 气管插管类（约 997 条，含经口/经鼻） | 需确认是否含气管切开、是否排除无创通气 |
| 其他（鼻胃管、引流管等，不计入三类分母） | `tube_biweiguan` 等 | — |

**待确认**：把这上百个 code 精确映射到三类，需要院感科和 ICU 护士站对着本院实际管路字典签字确认，系统不擅自归类。

## 5. 发生率计算公式

| 指标 | 分子（医生已确诊） | 分母 | 结果 |
|---|---|---|---|
| CLABSI 率 | 统计期内 CLABSI 确诊例数 | 中心静脉导管日合计 | 例 / 1000 导管日 |
| CAUTI 率 | 统计期内 CAUTI 确诊例数 | 导尿管日合计 | 例 / 1000 导管日 |
| VAP 率 | 统计期内 VAP 确诊例数 | 机械通气日合计 | 例 / 1000 通气日 |

对应已预留的质控编码：quality_24(VAP)、quality_26(CRBSI)、quality_425(CAUTI)。一期分母先算到"设备日"层，分子靠医生确诊回写 `patient_tube.is_infect` 或独立确诊记录表。

## 7. 一期开发范围建议

1. 建"管路分类字典"配置页（先由院感科把 tube_code 归到三类）；
2. 自动算三类设备日（中心静脉导管日 / 导尿管日 / 机械通气日）；
3. 疑似院感名单页：带管 + 培养/体温/WBC 证据，按患者列时间线，标记"疑似"；
4. 医生确诊/排除操作，回写确诊标记；
5. 脓毒症疑似名单（复用 SOFA/乳酸）；
6. 系统内待办 + 弹窗预警。

**明确不做**：自动下院感确诊结论、VAE 的 VAC 层（待 PEEP/FiO₂ 核实）、短信/院内通讯、完整药敏结构化报告。

---

## 8. 需院感科/信息科会签确认的清单

1. PICC 是否计入"中心静脉导管"分母；还有哪些 tube_code 算深静脉导管；
2. 机械通气日是否含气管切开、是否排除无创通气；
3. VAP 采用 NHSN VAE 三层，还是沿用本院旧的"临床 VAP"口径；每日 PEEP/FiO₂ 能否从 ICU 系统取到；
4. 血/尿培养在 ICU 库里的项目编码与"阳性/阴性/真菌"取值格式；
5. 确诊事件是写回 `patient_tube.is_infect`，还是新建独立确诊记录表（建议后者，保留修改留痕）；
6. 统计周期（月/季度）与科室范围。
