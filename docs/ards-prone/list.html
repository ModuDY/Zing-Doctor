列表页设计要点

  1. 1口径为「一次俯卧位疗程」，与「患者」分离：同一患者多次俯卧位各自成行，便于统计例次、时长与并发症发生率。
  2. 2行内直接给出结果指标（P/F 变化、最低 ΔP、并发症），不用点开就能判断这次俯卧位有没有效。
  3. 3状态区分「进行中 / 已提交 / 已终止 / 草稿」；进行中记录实时显示已填进度与当前时点。
  4. 4「复制新建」用于连日俯卧位：带入患者信息与参数模板，时点数据清空，避免逐项重录。
  5. 5已提交记录修改留痕：显示最后更新人与时间，修改内容进入审计日志（谁在什么时候改了哪个时点的哪一项）；不限时更正，不设 30 分钟窗口。
  6. 打印/归档后调用「参数设置」中配置的现有归档接口回传；回传状态在列表可见（已归档 / 失败待重试 / 未回传），失败可手动重传，避免纸质归档与电子记录不一致。
  7. 列表与填写页不做告警：异常值仅在填写页按内置参考区间标红，本页只呈现疗程结果（P/F 变化、最低 ΔP、并发症），由人工核对。
