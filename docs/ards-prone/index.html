生命体征（HR / BP / MAP / RR / T / SpO₂）监护仪（自动采集） 同上，oi_hr / oi_hxpl / oi_spo2 / 有创收缩压·舒张压优先 同上，且列表页显示「数据不全」
血气（pH / PaO₂ / PaCO₂ / HCO₃⁻ / BE / Lac）LIS 检验同步 patient_info_lis_item 按项目名称（PH值、氧分压、二氧化碳分压、乳酸…）取时点窗口内最近一次报告 窗口内无数据 → 置空标「未采集」，转手工录入（不沿用历史值）
打印 / 归档现有归档接口（回传） 打印并归档时生成 PDF（含记录编号、页码、打印人），调用「参数设置」中配置的现有归档接口回传，记录回传状态与文档号 列表页标记「失败 · 待重试」，支持手动重传；同一记录重复回传不产生重复文档
缺失项（Ppeak / Pplat / HCO₃⁻ / BE 等）手工录入 观察项/检验项目中无对应数据元的参数，一律标记为「手工」来源，界面角标与自动值区分 —
氧合指数 P/F、ΔP、P/F 变化、持续时长系统计算 PaO₂ ÷ (FiO₂/100)；Pplat − PEEP；相对翻身前差值；结束 − 开始 缺任一项则显示「待补」而非 0
镇静镇痛、安全评估、并发症、终止指征、签名手工录入 结构化选项 + 文本，提交时双人签名 —
v4 已确认口径：① 观察项/检验中缺失的参数（Ppeak、Pplat、HCO₃⁻、BE 等）按手工录入处理，界面角标与自动值区分； ② 采集窗口：生命体征/呼吸机 ±15 min、血气/检验 ±60 min，窗口内无数据一律置空转手工， 不沿用历史值、不做陈旧判定；③ 提交后不设修改时限，更正全程留痕； ④ 归档调用参数设置中配置的现有归档接口（与 APACHE II、SOFA 评分归档同一接口、传参一致，仅文档类型编码不同），不新开发接口，失败可重传且幂等； ⑤ 不做告警、不提供阈值配置：异常值仅按内置固定参考区间标红作视觉区分； ⑥ APACHE II 由「参数设置」中的一个开关控制，作用于填写页、文书预览、打印文书、回传文书四处，默认显示、全院统一，关闭后整行重排不留空位； ⑦ 移除告警与沿用后的残余风险（RISK-002、RISK-005，3×2=中）已由临床评审接受，系统不实现任何告警或补偿代码，异常发现依赖界面标红与打印件人工核对。
本设计稿为评审用静态原型，不含真实患者数据（示例均为虚构）。打印版式、时点模板与数据元映射需经临床与信息科确认后基线化； 实现阶段需补齐：需求登记、危害分析与风险控制、接口控制文件、追溯矩阵与验证用例（见同目录《设计方案.md》）。
