设计要点

  1. 1顶部常驻患者与疗程信息（第几天/第几次），并保留「历史记录」入口，便于对照前几次俯卧位的氧合反应。
  2. 2持续时长、驱动压 ΔP、氧合指数 P/F、P/F 变化 4 项由系统计算，不允许手改，避免口径不一致。
  3. 3两种录入模式：横表适合一次性补录与通盘对比；单时点模式给床旁/平板，一次只填一个时点。
  4. 4横表冻结左侧三列并横向滚动；表头显示每个时点的计划时间，当前时点高亮、已填时点打勾。
  5. 5并发症、终止指征改为结构化勾选项，后续可直接统计发生率，不用再翻自由文本。
  6. 数值按内置固定参考区间标红（MAP<65、SpO₂<90、Pplat>30、ΔP>15、P/F<150、Lac>2.0、pH<7.30 等）：仅为视觉区分，不弹窗、不提示、不阻断、不提供阈值配置。
  7. 安全评估类参数用「固定 / 渗血 / 受压发红」等状态标签，非数值项也能一眼看出异常。
  8. 7自动采集与检验同步值不可直接改写；确需修正时走「人工修正 → 填写原因 → 留痕」，原值保留。
  9. 每个单元格可下钻查看「来源系统 + 采集时间 + 原始值」。
  10. 断网/接口故障时可离线录入，恢复后自动同步。采集窗口内无数据一律置空标「未采集」并转手工录入，不沿用历史值、不做陈旧判定；本例 8h 时点血气无新报告，故整列为空待手工补录，氧合指数显示「待补」。

监测时点配置

默认 11 个时点；可按科室 / 患者增删
采集窗口：生命体征 / 呼吸机参数 ±15 min；血气 / 检验 ±60 min（非连续项目）。
窗口内取最近一条 → 标「已采集」；窗口内无数据 → 置空标「未采集」，由护士手工录入； 不沿用历史值、不自动推算。
序号时点名称相对开始偏移计划时间 采集状态数据来源操作
删除已填写的时点：不物理删除数据，仅标记为「已移除」，历史查询、统计与打印仍可追溯； 新增时点按「相对俯卧位开始的偏移」自动生成计划时间，并进入采集提醒队列。

时点配置设计要点

  1. 6时点是「模板 + 实例」：科室模板决定默认 11 个时点，单次记录可在此基础上增删，互不影响。
  2. 每个时点带「相对开始偏移」（如 +2h），保存后自动推算计划时间；俯卧位开始时间改了，计划时间整体顺延。
  3. 采集状态仅区分「已采集 / 待采集 / 已关闭」三种中性状态，不做滞后提醒与告警。
  4. 已填数据的时点不允许静默删除：需二次确认并说明原因，数据保留可追溯（满足记录不可篡改、修改留痕的要求）。

打印设计要点

  1. A4 横向、8pt 字号、全边框，37 行 × 11 列完整还原纸质记录单版式；预览即真实版式（所见即所得），可直接归档。
  2. 自动计算项（ΔP、P/F、P/F 变化、持续时长）打印为灰底，与人工录入项区分；超出内置固定参考区间的值保留红字（仅视觉区分，不做告警）。
  3. APACHE II 由「参数设置」开关控制：开启时随抬头输出；关闭时该格不输出、整行重排，不留空白占位。开关同时作用于填写页、文书预览、打印文书与回传文书。
  4. 页脚固定输出：记录编号、归档文档号、打印时间、打印人、页码（第 X 页 / 共 Y 页），来源标注「自动采集 / 检验同步 / 手工录入」。
  5. 打印后调用「参数设置」中配置的现有归档接口回传；回传记录文档号与状态，失败可重传，同一记录重复回传不产生重复文档。
