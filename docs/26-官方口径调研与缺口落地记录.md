## 二、官方口径的关键版本差异（易踩坑）

1. **抗菌药送检率**：2015 版病原学检验**包含**降钙素原（PCT）、白介素-6；2024 版
   **明确排除** PCT/IL-6（仅含微生物培养药敏、显微镜检查、免疫学检测、分子快速诊断、
   相关标志物；G/GM 试验属免疫学检测，计入）。quality_430（白介素）按 2024 版
   不应计入送检率分子，仅作扩展监测。
2. **治疗性抗菌药物**：两版口径一致，均为「用药目的为治疗」的全身给药——需要医嘱
   侧「用药目的」字段支撑（见下文待确认清单），故 quality_427-432 维持占位不出假数。
3. **非计划转入 ICU 率**（2024版 ICU-14）：分母是「同期**转入 ICU 的手术患者**总数」，
   不是全部转入；判定=非早期预警转入或麻醉诱导前无术后转入计划。现有 quality_21
   的诊断识别口径偏宽，接入手术计划源后需按官方口径收窄。
4. **48h 再插管率**：分子不含非计划拔管后再插管；源字段无法区分，按「排除非计划
   拔管行」近似（remark 已注明）。

   MySQL 镜像在 `sql/mysql/` 同名文件；install.sh 清单已登记，全新安装自动带出。
2. 发布新包（后端 + 前端一起发，前端含导管感染确诊页、导管统计增强、VAS/FOUR 区块、

3. 触发重算：`POST /api/quality/recalc`（或等 QualityDailyTask 每日批算）。
4. 核对：质控看板导管域/DVT 域/床位域指标出数；导管统计页年度视图可切、导出可用。
